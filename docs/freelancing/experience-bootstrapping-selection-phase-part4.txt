EXAMPLE WORKFLOW: EMAIL PROCESSING AGENT
-----------------------------------------
This is a realistic, impressive workflow to implement:

WORKFLOW DESCRIPTION:
Agent monitors incoming emails, classifies them, extracts key information, 
drafts responses, and routes complex cases to humans.

STEP-BY-STEP EXECUTION:
1. Monitor incoming emails (webhook or polling)
2. Classify email (support, sales, general, spam)
3. Extract key information (customer name, issue, urgency)
4. Search knowledge base for relevant information (RAG)
5. Draft response using retrieved context
6. Score confidence (can agent answer accurately?)
7. If high confidence: Send response automatically
8. If low confidence: Route to human for review
9. Log all actions in database
10. Update CRM/helpdesk system

TOOLS NEEDED:
• Email API (Gmail API, SendGrid, or similar)
• RAG system (can reuse from previous projects)
• Database (store email data, responses)
• CRM/Helpdesk API (optional integration)
• LLM API (OpenAI for classification and response generation)

TECHNOLOGY STACK:
-----------------

AGENT FRAMEWORK:
• Primary: LangChain Agents (ReAct pattern)
• Alternative: CrewAI (for multi-agent systems)
• Alternative: AutoGen (Microsoft's framework)

BACK-END:
• Framework: Python FastAPI
• Agent Framework: LangChain Agents
• LLM: OpenAI API (GPT-4 with function calling)
• Tools: Custom tool implementations
• Database: PostgreSQL (for workflow history, state)
• Task Queue: Celery or RQ (for async agent execution)
• WebSockets: For real-time dashboard updates
• Deployment: Railway, Render, or Fly.io

FRONT-END (DASHBOARD):
• Framework: Next.js 14+
• Styling: Tailwind CSS
• UI Components: shadcn/ui
• Real-time Updates: WebSockets or Server-Sent Events
• Charts: Recharts (for metrics visualization)
• Deployment: Vercel

TOOL IMPLEMENTATIONS:
• Web Search: SerpAPI, Google Custom Search, or web scraping
• Database: SQLAlchemy or direct PostgreSQL queries
• File Operations: Python file I/O
• Email: Gmail API, SendGrid API, or IMAP/SMTP
• APIs: requests library for REST APIs

DEVELOPMENT TOOLS:
• Version Control: Git + GitHub
• Environment Variables: .env files
• API Testing: Postman
• Code Quality: Black, Ruff, mypy
• Monitoring: Sentry (error tracking)
• Logging: Structured logging (Python logging)

AGENT EXECUTION FLOW:
1. Trigger received (webhook, API call, scheduled)
2. Agent receives goal/task
3. Agent plans steps (LLM reasoning)
4. Agent selects tool to use
5. Tool executes (web search, API call, etc.)
6. Tool returns result
7. Agent analyzes result
8. Agent decides next step (continue, retry, escalate)
9. Repeat steps 4-8 until goal achieved or error
10. Log all actions to database
11. Update dashboard in real-time
12. Return final result
